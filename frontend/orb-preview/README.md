# 球体首页交互原型

本轮由用户明确授权 Codex 搭建前端；后端实现交给 WorkBuddy。

在项目根目录运行 `python3 -m http.server 8791 --bind 127.0.0.1 --directory frontend/orb-preview`，打开 http://127.0.0.1:8791 。也可直接打开 index.html。

- 首页：左右滑动、方向按钮、键盘方向键选择球体；点击当前球体或进入按钮打开任务。
- 跑步：本地图片预览、格式/大小错误、模拟提交状态；下方个人/队伍榜。
- 步数：绝对日步数模拟同步，重复同步不累计，个人历史总步数只在资料展示。
- 左上资料：会话内修改展示名；右上排行榜：切换项目及个人/队伍。
- 早起、阅读、拜访：预留入口及未开放状态，规则待确认。
- Escape 或返回首页保留当前项目；支持减少动态效果设置。

所有身份、排名和数值都是示例。运行于页面内存，刷新复位；没有发送截图、真实 OCR、微信接口、用户数据库或真实打卡判定。app.js 内 demoAdapter 是后端替换边界；本地文件校验不能代替服务器校验。

后端约定见 ../../docs/ORB-UI-BACKEND-HANDOFF.md。原有 server/、sports-demo/ 未修改。

## 黑白平面修订
用户指定黑白主体、亮蓝色操作按钮；项目圆形无渐变或阴影。首页显示本机当前时间，每 30 秒刷新；06:00–18:00 为日间外观，其他时间为夜间，可手动切换。该时间规则仅影响外观，未与业务打卡截止时间关联。此交付仍为手机网页原型，尚未转换微信小程序。

黑白蓝修订已检查：390×844 日/夜手机、1280×900 桌面、320×568 小屏（无横向溢出，内容可滚动），外观双向切换与任务个人/队伍切换。旧设计色表的检测提示已通过新版设计说明更新处理。

最新用户修订：项目圆形各有独立平面配色（早起琥珀、跑步橙、步数青蓝、阅读紫、拜访玫红），当前和邻项都保留项目色，用大小、位置、文字及图标识别；背景仍黑白、操作仍亮蓝，不用光影。UI 参考 ChatGPT、苹果、DeepSeek 的简洁层级与留白。此条覆盖此前项目圆形黑白/描边的约定。

最新用户微调：项目圆形允许少量光影与轻微厚度；按钮改柔和圆角（主要16px、其他12px），不再使用4px方角。类别配色、黑白背景与亮蓝色主要操作保留。以此条覆盖此前完全无光影的约束。

最新配色修订：项目提高明度、降低饱和度，早起奶油黄、跑步浅蜜桃、步数雾蓝、阅读淡薰衣草、拜访柔粉；图标和名称使用深色同色系。每个圆形左上柔光、下方小柔影，保持黑白背景和亮蓝操作按钮。此条覆盖之前较暗的浓色项目配色。

## 液态玻璃视觉试版（待用户选定）
当前 index.html 在 app.css 后加载 glass.css：浅色项目透色、背景柔化、细亮边、局部反光和向下柔影；黑白页面、亮蓝主要操作与原有交互保留。圆形背后用轻量色带作为透光参照。使用网页 CSS 近似玻璃观感，并非苹果原生 Liquid Glass 或真实物理折射。提供减少透明效果与不支持 backdrop-filter 时的实色回退。移除 index.html 中 glass.css 的引用即可恢复上一版，不需要修改后端。此为视觉比较试版，未确定为最终风格。

最新首页交互：移除独立的蓝色进入按钮，项目下方改为项目用途说明、体验状态和轻量下滑提示；点击当前圆形、提示文字、PageDown 或首页底部向下滚动可进入。手机在圆形/信息区域向下拖动超过65px进入，横向滑动仍切换项目；短屏可从其他页面区域正常滚动。任务页上传、同步等操作按钮保留。
