## 打开

推荐双击项目根目录的 `启动设计预览.command`。它从本目录启动本地服务并打开浏览器；关闭启动窗口不影响预览，重启电脑后可再次双击。

也可手动启动：

在 `Hongxin-Program` 目录执行：

```sh
python3 -m http.server 18874 --bind 127.0.0.1 --directory frontend/hongfeng-preview
```

浏览器打开 <http://127.0.0.1:18874/>。不需要安装依赖。结束预览可在服务窗口按 Control+C。

- 运动 / 读书 / 拜访：`/#/move`、`/#/read`、`/#/visit`

## 当前交互

- 首页上下滑动、触控板纵向滚动或方向键：切换三项目照片滚轮。
- 点击当前照片或当前名称、按 Enter：整体左滑进入次级页。
- 点击相邻照片或其他名称：先选中；次级页左侧文字导航可直接切换模块。
- 次级页圆形返回按钮留出14px左边距；首页隐藏，进入完成后渐显；返回保留选择。
- 首页向右滑进入专属早起页，早起页向左滑返回首页；鼠标拖动、触屏、Mac触控板横向滚动均有处理。
- 首页右上保留早起点击入口；没有第四个轮播项，没有额外提示条。
- 早起页中央圆形按钮，Big Sur海岸 / Catalina海岛 / Mojave沙丘背景可切换；运动模块内不再放起床打卡。
- 系统减少动态效果时保留操作与状态，减少空间动画。

## 早起页与演示边界

按北京时间展示05:30–05:31；原型暂采用 `[05:30:00, 05:31:00)`，不支持超时补签。真实实现的权威时间来源与网络延迟处理仍须明确。

底部“预览时段”下拉可模拟未开始、倒计时、打卡、结束、步数状态；选择05:30可体验按钮完成反馈。体验模式有明确标识。状态仅保留在本页内存；没有真实用户、服务端判定、上传或持久化记录。

运动、读书、拜访次级内容仍为界面预览。不得将本版本当作完成真实业务闭环的产品。

## 文件与素材

- `index.html`、`style.css`、`app.js`：主界面与三模块导航。
- `morning.css`、`morning.js`：独立早起空间、双向手势及演示状态。
- `assets/SOURCES.json`：三项目示意照片来源；`assets/macos-landscape-sources.json`：当前macOS风景来源；`assets/morning-sources.json`：保留的历史湖畔素材来源。JPEG亦嵌入来源。
- `proof/morning-update/`：本版早起状态与风景截图；`proof/`顶层保留前版截图用于对照。

图片为设计示意，非员工或客户的真实记录。玻璃效果是网页近似，不是Apple原生材质或物理折射模拟。Git记录仅保存在本地；网站已单独发布，本次归档不触发再次部署。
