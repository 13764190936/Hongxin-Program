# 首页纵向滚轮｜可操作原型

本轮交付可直接拖动、点击、键盘操作的隔离原型；未接入 `orb-preview`，未改动任何业务页面。

## 运行

```bash
cd Hongxin-Program
python3 -m http.server 8812 --bind 127.0.0.1 --directory frontend/home-wheel
# 打开 http://127.0.0.1:8812/prototype/index.html
```

## 交互

- 上下拖动或滚轮：只切换选中项，松手吸附；可循环，支持反向与中途接管。
- 点击居中项：进入对应次级页（占位内容）。
- 点击上下相邻项或名称：先居中，不进入。
- 键盘：`↑` `↓` 选择，`Enter` / `Space` 进入，`Esc` 返回。
- 返回按钮或浏览器返回：回到首页并保留上次选择。
- 系统开启“减少动态效果”时：取消惯性与过渡，操作仍可用。
- 拖动结束会吞掉紧随其后的那一次点击，避免松手误进入。

## 边界

- 次级页是占位页，只验证进入、返回与页面滚动，不包含起床/步数/跑步等业务规则。
- 未做真机触摸、微信开发者工具、跨浏览器与帧率测试。
- 造型、字体与最终动效参数仍可调整；接入现有首页前需再确认。
