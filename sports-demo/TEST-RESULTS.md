新增 5 个并发回归用例（`test/concurrency.test.js`，使用延迟分析器在真实 HTTP 上制造并发窗口）：

1. 同 Key 同请求体并发：两个响应都 200 且返回同一记录 ID，只有一条落库；一个 `replayed: false`，等待方 `replayed: true`。
2. 同 Key 不同请求体、首个请求仍在分析中：后到请求立即 `409 IDEMPOTENCY_CONFLICT`，首个请求随后正常成功。
3. 同人同日、不同 Key/图片并发：分析器同时放行后，仅一条 200，另一条 `409 RUN_ALREADY_CHECKED_IN`，落库一条。
4. 跨身份、同一图片字节并发：仅一条 200，另一条 `409 IMAGE_ALREADY_USED`，该 SHA256 只落一条。
5. 失败不污染重试：分析器首次返回 `503 ANALYZER_UNAVAILABLE` 后无幂等缓存/占位；同 Key 同体重试真正重新执行并成功，再次提交正常回放且记录 ID 相同。
