## 4. 什么能用，什么是假的

### 真的能用（后端已实现并测过）

- 员工提交四项行动 → 服务端校验（窗口/参数/幂等/企业归属）→ 落库 → 榜单实时变化 → 主管可见 → 导出 CSV 带留痕
- 早起窗口：半开区间 `[05:31:00, 05:32:00)`，按**客户端点击时刻**判定，与服务端偏差 >180 秒转「待核」
- 幂等：同 `idempotencyKey` 重复提交不产生第二条
- 企业隔离：A 企业管理员查不到 B 企业（数据层强制）
- 权限：员工访问管理接口返回 403；导出写 `export_logs`

### 假的 / 没做的（别当成已完成）

| 项 | 现状 |
|---|---|
| 登录 | 用请求头 `X-Test-User` 直接传用户 id。**任何人知道 id 就能冒充**，只能本地/演示用 |
| 图片上传与 OCR | 只存一个字符串引用，识别是假的。晨跑提交一定进「待核」，并打 `ocr_is_mock` 标记 |
| 阅读计时 | 纯客户端计时，改个变量就能刷，无服务端心跳 |
| 课程内容 | 没有正文、章节、视频。页面明确写"待课程方提供" |
| 审核流 | `reviews` 表在，接口没做。待核记录只能躺在库里 |
| 小程序端 | 一行没写。现在的是网页 |
| 培训机构专用管理后台页面 | 按负责人决定不做，只保留接口与导出；此项不取消主管作为产品用户的可视化 UI（2026-11-04 澄清，未核验现有实现） |

## 5. 五条硬约束（违反会被打回）

1. **不合并排行榜口径。** 只做单项目排名，不做"综合分"；只做小组内/企业内，不做跨企业、省级、全国。请求 `metric=composite` 或 `scope=national` 必须返回 422。
2. **早起按客户端时刻判定**（负责人明确选择），但不能因此变成没有审计：偏差超 180 秒必须进「待核」，待核不计入榜单。
3. **不做顺手改造。** 当前处于"一轮只打磨一个功能"阶段，禁止一次改多个页面。
4. **不写"完成了 XX"。** 只写做了什么文件、跑了什么检查、结果是什么。没验证的必须写在「未验证」里。
5. **不提交**：数据库文件、真实手机号、密钥、`.env`。

## 7. 已经踩过的坑（省你时间）

1. **`node:sqlite` 需要 Node ≥ 22.5**，且 Node 22 里会打 experiment 警告，不影响运行。
2. **日期计算不要混用**：用 `+08:00` 构造时间再用 `getUTCDay/getUTCDate` 读会跨时区算错。日期加减一律用纯 `YYYY-MM-DD` 字符串算术（见 `clock.js`）。
3. **对外输出时间一律用北京时间字符串**，不要吐 `toISOString()`，用户看到 `05:40Z` 会以为错了。
4. **部署站带 `?sharecode=`**，页面内的 `fetch('/api/…')` 必须透传这个参数，否则被网关返回"链接不完整"的 HTML，前端 JSON 解析直接崩。三个页面已注入修补。
5. **函数作用域**：详情页曾因把 `head()` 定义在 `subView` 内部、却在顶层函数里调用而整页白屏。改页面后必须跑一次渲染检查。
6. **没有浏览器就别声称页面能用**。接口通过 ≠ 页面渲染通过。已有办法：桩 DOM + 真接口跑渲染（见 DEVLOG 0009）。
