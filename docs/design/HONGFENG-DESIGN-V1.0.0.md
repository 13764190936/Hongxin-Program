## 已确认的设计

沿用国际主义平面设计 × Apple 极简主义，使用既定白、深蓝、红、浅蓝。首页大标题为“宣布一个不可能的未来。”；下方保留原品牌标语“实现一个不可能的未来。”，两者不混同为未经确认的全局品牌改名。

三个项目采用真实示意照片，照片上保留项目名称，旁边另有运动 / 读书 / 拜访文字选择器。删除首页序号计数、插画、英文编号及额外早起提示条。照片使用克制的玻璃窄边，早起按钮采用透明圆形；这是本轮明确批准的局部材质，不扩展成全站玻璃模板。

## 已确认的交互

1. 首页纵向循环滚轮只选择功能，点击当前项才进入；取消旧上滑进入、下拉返回、PageDown进入等逻辑。
2. 三项目次级页从右侧进入，首页整体左滑；左侧保留文字模块导航，支持直接切换。
3. 次级页返回为圆形箭头，左边距14px，首页不显示；左滑进入完成后渐显。返回保留选中项。
4. 起床打卡不在运动模块内，也不是第四个拨轮项目。它是首页左侧的专属空间：首页右滑进入，早起页左滑返回。另保留首页右上点击入口。
5. 横向手势支持鼠标拖动、触屏与Mac触控板；纵向滚轮仍只切换项目；短滑或反向回到起点，不改变路由。
6. 早起页全幅风景、中央圆形打卡按钮，湖畔 / 晨雾背景可切换。聚焦每天05:30–05:31一分钟窗口。

以上早起归属与导航规则覆盖总纲原文中“起床打卡归运动”的旧界面分组，不改变运动、阅读和拜访的业务需求，不增加团队、排名、评分等范围。

## 运动手感基线

采用连续位置与速度模型，不逐次重启固定时长缓动：跟随omega32、吸附omega24，触控板纵向增益0.5，拖动距离尺度1.45倍；松手预测80ms并限制惯性距离。照片旋转基准58°，沿连续弧形轨迹移动，消除中心深度折点与整片动态背景取样。

照片标题桌面38px / 手机30px。页面转场保留变速收放；支持减少动态效果。参数属于当前已接受原型，后续真机调优以实际体验为准。

## 真实能力与未决规则

- 原型无后端、微信登录、真实账户、图片上传或持久化；次级业务页面是占位预览。
- 早起按Asia/Shanghai显示，临时采用半开窗口；底部体验模式模拟05:30:20并标明“不保存记录”。内存中的完成状态只用于反馈和防重复体验，不是真实打卡凭证。
- 真实服务端时间、精确端点、网络延迟、权限、历史存储等仍须按需求与问题表确定和验证。
- 未核验实体手机、微信环境、Safari、低端机帧率或真实后端。
