## 2. 参考视频拆解

**素材**：9.07 秒、2930×1998 录屏，Chrome 中的 shadcnblocks `coverflow44`。按 0.5 秒抽帧，2.9–4.3 秒按 0.1 秒补帧。

### 2.1 直接观察（事实）

1. 中心项正面完整；上下相邻项被压成窄带，上项上边更窄、下项下边更窄，是绕 X 轴旋转而非单纯缩放。
2. 相邻项更暗、更模糊，画面上下边缘有白色渐隐，越远越淡。
3. 切换时所有项沿同一纵向轨迹连续移动，没有横向位移。
4. 名称独立成列，当前行字号与字重明显更大，其余为浅灰小字。
5. 计数从 `01/07` 到 `05/07`，也可反向回到 `03/07`，首尾无空白。
6. 9.07 秒内没有自动轮播。
7. 中心图约 3:2，圆角约 8–10px（按 900px 宽抽帧估算，非页面实测）。

## 3. 现有页面诊断与复用

塑料感来自五色糖果圆形、圆形+图标+文字堆叠、遗留柔光与玻璃、以及五套并行入口（箭头、圆点、上滑提示、PageDown、底部滚动）。新首页只保留“滚轮 + 名称 + 一条提示”。

- **保留**：`state`、`render()` 路由、`demoAdapter`、次级页表单与榜单逻辑、焦点管理、减少动态判断。
- **替换**：首页结构与样式、五项任务收敛为运动/读书/拜访。
- **删除**：上滑进入、下拉返回、PageDown、滚动进入、圆点、左右箭头及对应文案。
- **未动**：`server/`、`sports-demo/`、`orb-preview` 以外的任何文件。

## 4. 构图

### 4.1 桌面

```
HONGFENG 鸿风                          2026.11.14 —— 01 / 03

每日行动 / DAILY PRACTICE        ┌ 相邻项：透视压缩 ┐
今天，                            │ 拜访              │
选一件事。                        │ 运动（当前）       │
— 完成一个不可能的未来             │ 读书              │
运动、读书、拜访。每天完成一件。   └──────────────────┘

────────────────────────────────────────────────────────
↕ 上下滑动选择 · 点按当前项进入          ↑ ↓ 选择 · Enter 进入
```

三块：左编辑区、中滚轮、右名称列；名称固定三行，当前行更大更重，左侧红色竖线。顶栏只保留品牌、日期与计数。

### 4.2 手机（≤640px）

标题、标语置顶；滚轮在剩余空间居中，成为页面主体；名称列仍在右侧；底部只留操作提示。

### 4.3 尺寸

| 项目 | 桌面 | 平板 | 手机 |
| --- | --- | --- | --- |
| 图形 | 420×280 | 338×225 | 234×156 |
| 步距 | 214 | 172 | 119 |
| 当前名称 | 42px / 600 | 34px | 26px |
| 相邻名称 | 24px / 38% | 19px | 15px |
| 名称步距 | 58px | 52px | 40px |

### 4.4 图形

每张卡片 = 深蓝底 + 13% 红色竖带 + 白色几何符号 + 一处红点。

| 模块 | 符号 |
| --- | --- |
| 运动 01 | 上升台阶，红点在最高处 |
| 读书 02 | 对开书页，红色书签 |
| 拜访 03 | 两个节点连线，红色连接点 |

红色竖带同时承担编号区，三张卡片叠起来形成一条断续的红色脊柱，既是品牌色，也解决“太冷”。

### 4.5 当前选择

尺寸、位置、字重、红色竖线、顶栏计数、焦点环、`aria-current` 共同表达，不只靠颜色。

## 5. 交互实现

| 规则 | 实现 |
| --- | --- |
| 上下滑动只切换 | 滚轮区域 pointer 拖动，只改位置，不导航 |
| 点击当前项进入 | 居中且已吸附时进入 |
| 点击相邻项只选中 | 计算最近目标后动画居中，不进入 |
| 返回保留选择 | 首页不重建，位置值保留 |
| 取消旧手势 | 已删除上滑进入、下拉返回、PageDown、滚动进入 |
| 键盘 | `↑` `↓` 选择，`Enter` / `Space` 进入，`Esc` 返回 |
| 不再整屏上拉 | 220ms 淡入 + 8px 轻移；返回 160ms 反向 |
| 次级页正常滚动 | 手势只绑定滚轮；次级页恢复文档滚动 |
| 不误触 | 拖动结束吞掉紧随其后的一次点击 |

### 5.1 拖动与吸附

- 位置 `p` 为浮点数，拖动时 `p -= dy / 步距`，1:1 跟手。
- 松手按速度前推，最多 0.34 格，避免一次拖动跨两格；只允许向最近整数吸附。
- 新手势会立即取消进行中的补间，从当前位置接管，不排队。
- 循环通过 6 个槽位（3 模块 × 2 副本）映射到 `[-1.5, 1.5]`；超出范围的副本隐藏，不进入 Tab 序。

### 5.2 名称列

固定三行（上一项 / 当前 / 下一项），不做连续滚动，避免拖动中文字叠在一起。跨过半格时更新文字，并用 170ms 淡入提示变化。

### 5.3 无障碍

`role="listbox"` + 隐藏 `option` + `aria-activedescendant`，焦点停在滚轮容器上；选中变化通过 `aria-live` 播报；焦点环始终可见。

### 5.4 减少动态

关闭补间、惯性、详情页转场与名称淡入，操作方式不变。

### 5.5 导航

进入：首页隐藏，次级页淡入并上移 8px（220ms）。返回：次级页淡出 160ms，首页恢复并聚焦滚轮。`history.pushState` 支持浏览器/平台返回。

## 6. 本轮验证

### 6.1 自动化（无头 Chrome + 减少动态模式）

脚本按真实事件序列驱动，读取原型内部状态，结果：

| 检查 | 结果 |
| --- | --- |
| 初始状态 | p=0，index=0，详情未打开 |
| 拖动 160px | p=0.87 → 吸附到 1，未进入 |
| 松手后立即点击 | 被吞掉，detail=null |
| 点击居中项 | detail=1，首页隐藏 |
| 返回 | detail=null，index 仍为 1 |
| 点击相邻名称 | 目标 2，settle 后 index=2，未进入 |
| `↑` | 目标 1，settle 后 index=1 |
| `Enter` | detail=1 |

### 6.2 构图

- 桌面 1440×900、手机 390×844 截图检查：无横向溢出，标题在顶部，名称三行不重叠。
- 拖动中间态截图：卡片有明确纸色描边，名称不堆叠。

### 6.3 未验证

- 真机触摸与惯性手感；无头环境 rAF 会被节流，动画曲线只能靠真机确认。
- 微信小程序 webview、读屏、低端机帧率。
- 未做跨浏览器（仅 Chrome）。
