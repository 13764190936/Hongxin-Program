# 客户待确认问题表

> 本文仅记录待确认问题，不代表相关功能已经实现。

## 处理原则

- 先推进已经确认的大体功能；只有用户明确表示无法回答的问题，才列为待问客户，不反复追问。
- 演示采用的默认值必须明确标注为演示默认值，不能视为客户确认。
- 已确认：设置个人日榜和队伍日榜两个榜单，每日重新排名；累计步数仅供个人展示；截图必需。以上内容不再重复询问。
- 技术接入验证由开发负责，不转交给客户。
