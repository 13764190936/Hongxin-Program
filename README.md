# 鸿心徒步 · 重建项目

本仓库用于产品设计与WorkBuddy开发协作。当前阶段：需求调研和开发准备，尚无应用代码、服务器或上线环境。

## 从这里开始

1. [WorkBuddy接手说明](WORKBUDDY.md)
2. [产品需求与开发交接文档](docs/PRD.md)
3. [逐项功能与排行榜清单](docs/FEATURE_INVENTORY.md)
4. [待确认决策](docs/DECISIONS.md)
5. [开发任务](docs/BACKLOG.md)

负责人负责业务决策；产品与交互设计在文档中沉淀；WorkBuddy负责技术方案、代码实现和验证。现状、建议和待确认规则必须区分。

## 状态

- 已完成：普通用户端部分页面与功能调研、排行榜入口梳理、个人中心补充。
- 未完成：全部功能覆盖、关键统计口径、其他角色和后台、技术方案与实现。
- 技术栈：待提出并确认。
- 数据：仅使用虚构测试数据，不含旧系统真实用户记录。

## 协作方式

WorkBuddy可在有权限的GitHub账号下克隆本仓库，也可先打开本地目录。建议每次从main更新，在独立功能分支修改，通过PR说明改动、验证与剩余问题。

私有仓库需要WorkBuddy所使用的GitHub身份具备仓库权限；本仓库不会自动完成WorkBuddy账号连接或授权。
