# 鸿心 · 课程行动平台

**第一次来先读 [`docs/HANDOFF.md`](docs/HANDOFF.md)** —— 一页说清现在能跑什么、什么是假的、下一步做什么。

给客户演示的只有一个东西：**跑起来的产品演示页**。其余都是过程材料。

## 想直接看效果

**双击项目根目录的 `启动演示.command`**，会自己打开终端、启动服务、并弹出浏览器。

> 窗口要一直开着，关掉服务就停了（按 Control + C 停止）。
> 第一次双击如果提示"无法打开，因为来自身份不明的开发者"，右键 → 打开 → 仍要打开。
> 也可以手动跑：

```bash
cd server
npm start        # 数据库不存在时会自动写入虚构数据
```

打开后：

1. 默认是员工「林清和」——早起和晨跑已完成，留「阅读」「拜访」给你点。
2. 点「阅读」→ 开始计时 → 结束 → 勾选完成 → 保存，底部会提示 `已记录 · 阅读分钟 0 → 13`。
3. 去「排行」看数字变化；去「我的」切换身份成「温听」，看她的视角。
4. 刷新页面，数据还在。

URL 说明：

| 地址 | 是什么 | 给谁看 |
|---|---|---|
| `/` | **员工端界面**（手机竖屏，5 个 tab：今天/课程/排行/团队/我的） | **给客户看这个** |
| `/showcase` | 主管视角 + 证据链演示（提交后看数据落到哪） | 给客户解释"后台怎么拿到数据" |
| `/debug` | 技术调试台：接口、状态码、原始字段 | 只有你看 |

`/` 里点「我的」最下面可以切换身份，用来演示"同一个团队里，别人和主管看到的是什么"。

## 仓库里都有什么

| 路径 | 作用 | 状态 |
|---|---|---|
| `server/` | 后端（零第三方依赖，Node 内置 SQLite）+ 演示页 | **能跑** |

| `docs/ACTION-BACKEND-HANDOFF.md` | 负责人确认的产品方向 | 依据 |

| `docs/DECISIONS.md` | 已定决策与仍待确认项 | — |
| `docs/REVIEW-03.md` | 新方向的可行性评估与风险 | 历史评审 |
| `frontend/action-preview/` | 五页交互设计稿（今天/课程/排行/团队/我的） | **静态，给客户讲设计用** |
| `archive/prototype-v0.2/` | 上一版徒步小程序原型 | 已归档，不再维护 |

> 产品只有一个：`server/` 跑起来的那套。`frontend/action-preview` 是设计参考，`archive/` 是历史。
> 三套前端并存过一段时间，已收拢；现在视觉以演示页为准。

## 现在的真实进度

- 能做：员工提交四项行动 → 服务端判定（窗口/参数/幂等）→ 入库 → 小组榜变化 → 主管可见 → 导出 CSV。
- 不能做：微信登录、真实图片上传与 OCR、阅读心跳、审核界面、后台页面、小程序客户端、部署上线。
- 数据：全部虚构（两家企业、10 个用户、4 支队伍）。没有一条真实用户信息。

## 协作方式

`main` 为唯一分支。每次改动都追加 `docs/DEVLOG.md` 一条，写清做了什么、验证了什么、**哪些没验证**。

不提交：`.env`、数据库文件、真实手机号、密钥。仓库里不应出现任何真实员工数据。
